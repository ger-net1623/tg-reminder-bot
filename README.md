# Telegram Reminder Bot

Telegram-бот на Python для постановки и отправки напоминаний. Принимает время в естественном языке (`завтра в 19:00`, `через 30 минут`), хранит в SQLite, рассылает в назначенный момент.

**Стек:** Python 3.11 · aiogram 3 · aiosqlite · APScheduler-style asyncio loop · dateparser

## Возможности

- Создание напоминаний пошаговым диалогом (`/add`)
- Парсинг естественного русского ввода времени (`завтра в 19:00`, `через 2 часа`, `11.05 в 18:30`, `в пятницу в 19:00`, `12.05.2026 09:30`)
- Список активных напоминаний (`/list`) и удаление по номеру (`/delete N`)
- Отмена незаконченного диалога (`/cancel`)
- Все времена в часовом поясе Europe/Moscow (UTC+3); внутри — UTC
- Фоновый планировщик с точностью ±15 секунд
- Корректное завершение по Ctrl+C (graceful shutdown)
- Изолированные слои: `db` (хранилище), `time_parser` (парсинг), `handlers` (Telegram), `scheduler` (рассылка)

## Команды бота

| Команда     | Действие                                          |
|-------------|---------------------------------------------------|
| `/start`    | Приветствие и список команд                       |
| `/help`     | Справка с примерами форматов времени              |
| `/add`      | Создать напоминание (пошаговый диалог)            |
| `/list`     | Показать активные напоминания                     |
| `/delete N` | Удалить напоминание с номером N (например `/delete 3`) |
| `/cancel`   | Прервать текущий диалог                           |

## Установка и запуск

```bash
git clone https://github.com/ger-net1623/tg-reminder-bot.git
cd tg-reminder-bot

python -m venv venv
# Windows PowerShell:
.\venv\Scripts\Activate.ps1
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
```

Создайте `.env` (см. `.env.example`):

```env
BOT_TOKEN=your_telegram_bot_token_from_botfather
```

Запуск:

```bash
python bot.py
```

База данных создаётся автоматически в `data/reminders.db` при первом запуске.

## Структура проекта

```
tg-reminder-bot/
├── bot.py              # Entry point: загрузка конфига, старт бота и планировщика
├── handlers.py         # Обработчики команд и FSM-диалога /add
├── db.py               # SQLite слой (CRUD + smoke-тест)
├── scheduler.py        # Фоновый цикл: проверка БД и отправка напоминаний
├── time_parser.py      # Парсер естественного ввода времени → datetime UTC
├── requirements.txt    # Зависимости
├── .env.example        # Шаблон конфига
└── data/               # Создаётся при первом запуске
    └── reminders.db    # SQLite-БД с напоминаниями
```

## Архитектурные решения

- **Чистое разделение слоёв.** `db.py` ничего не знает про Telegram, `time_parser.py` - только про datetime. Это даёт возможность тестировать каждый модуль отдельно (см. `python db.py` и `python time_parser.py` - встроенные smoke-тесты).
- **UTC внутри, локальное время на границах.** Все datetime хранятся в UTC; конвертация в Europe/Moscow только для отображения и при разборе пользовательского ввода. Это устраняет целый класс багов с переходом на летнее время и поездками в другие TZ.
- **Простой polling-планировщик вместо APScheduler.** Цикл `asyncio` с интервалом 15 секунд выбран сознательно: для напоминаний с минутной точностью этого достаточно, а кода и зависимостей меньше. APScheduler уместен, если потребуется субсекундная точность или сложные cron-расписания.
- **MemoryStorage для FSM.** Достаточно для текущего объёма; если потребуется переживать рестарты - заменяется на RedisStorage за несколько строк.

## Smoke-тесты модулей

Каждый ключевой модуль можно проверить независимо без запуска самого бота:

```bash
python db.py            # CRUD-цикл на временной БД
python time_parser.py   # Прогон 9 типовых форматов ввода времени
```
